# Resource names removed in v0.7.23

These were in `strings.xml` (and eight translations) with **no reference of any kind** —
no `R.string.`, no `@string/`, no `getIdentifier`, no `int[]` of ids. They are text for
features that were not ported into this launcher: the web viewer (no `WebView` exists in
this codebase), the Docker UI, and their shared dialogs.

Removing them took the APK from 841,396 to 659,260 bytes. The text itself is in git
history — `git show v0.7.22:openandroiddex-launcher/app/src/main/res/values/strings.xml`.

What stays: `wb_no_window` and `wb_not_running`, which the launcher does read.
